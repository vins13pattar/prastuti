# Governance

Prastuti currently uses a maintainer-led governance model.

The repository owner is responsible for product direction, release decisions, security coordination, and final review of changes that affect pricing, credit accounting, privacy, provider contracts, or architecture.

Contributors influence the product through issues, discussions, design proposals, pull requests, testing, documentation, and review. Decisions should be recorded in public repository artifacts whenever they do not contain sensitive security or commercial information.

As the contributor base grows, this document should evolve to define additional maintainers, decision rights, conflict-resolution procedures, and a transparent path to maintainership.
